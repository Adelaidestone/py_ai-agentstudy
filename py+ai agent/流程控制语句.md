## while和for循环对比
### while
条件驱动循环（只要条件为True就继续循环）
写法灵活，尤其适合处理不确定循环次数的场景\
但是需要手动维护循环条件，维护不好容易死循环
### for
迭代驱动循环（遍历一个可迭代对象的每一项）
语法简洁，处理可迭代对象的首选，不容易发生死循环
只适合一开始就知道要循环几次的场景

## continue和break
*continue*  : 跳过本次循环剩余语句，随后进入下一次循环
break：立即终止循环，不再执行后续循环
```
##吃饭睡觉 第2天不准睡觉

    print(f"第{day}天")

    if day == 2:

        continue

    print("睡觉")
``````
综合案例
```  

"""

3个关卡 一个关卡一道题 答对进下一关 3关通过成功

答错重试 第3次错 游戏结束

输入为空 重新作答 不消耗时长

输入q 直接退出游戏

"""











questions =["第1题的答案是：","第2题的答案是：","第3题的答案是："]

answers =[1,2,3]

  

for i in range(3):

    wrong =0

    while wrong<=3:

        guess=input(questions[i])

        if int(guess) == int(answers[i]):

            print("进入下一关" if i<=2 else "恭喜你通关了")

            break

        if guess =="":

            continue

        if guess=="q":

            print("退出游戏")

            exit()

        else:

            wrong += 1

            print(f"答错了，还剩{3-wrong}次机会")

  

    else:

        print("答错3次，挑战失败")

        break
```
