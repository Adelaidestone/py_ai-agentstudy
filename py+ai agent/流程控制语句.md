## 双分支
```
双分支在if的基础上加了一个else
age = input("请输入你的年龄：")

age = int(age) #将输入的字符串转换为整数

if age>=18:

    print("你是成年人")

else:

    print("你是未成年人")

print("总之你就是猪")

```
## 多分支
```
age = int(input("请输入你的年龄："))

if age<10:

elif age<18:

    print("你是未成年人")

    print("你是成年人")

else:

    print("你是老年人")
```

## while循环
| 循环类型       | 描述                             |
| ---------- | ------------------------------ |
| [while 循环] | 在给定的判断条件为 true 时执行循环体，否则退出循环体。 |
| [for 循环]   | 重复执行语句                         |
| [嵌套循环]     | 你可以在while循环体中嵌套for循环           |
```
  

print("你现在身处密室，请输入密码逃脱")

Key = "Mussy520"

```````
