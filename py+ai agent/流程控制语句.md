## 双分支
```
双分支在if的基础上加了一个else
age = input("请输入你的年龄：")

age = int(age) #将输入的字符串转换为整数

if age>=18:

    print("你是成年人")

else:

    print("你是未成年人")

print("总之你就是猪")

```
## 多分支
```
age = int(input("请输入你的年龄："))

if age<10:

    print("你是幼儿")

elif age<18:

    print("你是未成年人")

elif age<65:

    print("你是成年人")

else:

    print("你是老年人")
```
