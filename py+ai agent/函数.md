官方定义：函数(function)是组织好的、可重复使用的、关于执行特定任务的代码块
## 函数作用
 * 代码复用：提高代码复用性，减少重复代码
 * 结构清晰，让程序易读
 * 模块化开发：把程序分成若干小功能，便于团队合作

## 位置参数
调用参数时，根据参数在函数定义中出现的顺序，把实参的值依次传递给对应的形参；使用位置参数时，不允许跳过某个位置的参数，去给后面的参数赋值
## 关键字参数
调用函数时，通过 ==形参名=值== 的形式传递实参
使用关键字参数允许函数调用时参数的顺序与声明时不一致

## 限制传参方式
具体规则,/前面只能用位置参数，*    后面只能用关键字参数；/ 必须在 * 前面
```
def greet(name,/,gender,*,age,height):

    print(f'我叫{name},性别{gender},年龄是{age}，身高是{height}cm')

greet('小王',gender='男',age=18,height=23)
```````

## 参数默认值
定义函数时，通过==形参名=值== 的形式，为参数指定一个默认值
注意：默认参数必须放在必选参数的后面，或者说：某个形参，一旦设置了默认值，那他后面的所有的形参，也必须要写默认值
```
def greet(name,/,gender,*,age,height=24):

    print(f'我叫{name},性别{gender},年龄是{age}，身高是{height}cm')

greet('小王',gender='男',age=18,height=23)
```````
print(),就设置了一个参数默认值end="/n"自动换行

## 可变参数
### 可变位置参数
在定义函数时，在形参名前加*，可以接收任意数量的位置参数，并打包成一个元组
```
def test1(*args):

    print(args)

test1('张三','李四')
```
### 可变关键字参数
定义参数时，在形参前加**，可以接收任意数量的关键字参数，并且打包成一个字典

## 全局作用域 vs 局部作用域
作用域-变量能起作用的范围

全局作用域:整个.py最外层的范围
全局作用域和全局变量，在程序调用时创建，程序结束后销毁

局部作用域:函数的内部范围
局部作用域和局部变量，在函数调用时创建，调用结束后销毁
![[Pasted image 20260610113021.png]]如果要在局部变量中声明全局变量
```
a = 100

b = 200

  

def test():

    global a

    a=300

    print(a)

    print(b)

  

test()

print(a)

print(b)


输出：300 200 300 200
```````
