# 88. 合并两个有序数组

> 🔗 [LeetCode 链接](https://leetcode.cn/problems/merge-sorted-array/) · `Easy` · `双指针`
>
> 📅 2026-05-20 · ✅ 独立 AC · ⏱ 10 min

---

## 题目

两个**升序**整数数组 `nums1`、`nums2`，长度分别为 `m`、`n`。请将 `nums2` 合并进 `nums1`，使合并后的数组同样**升序**。

- `nums1` 初始长度 `m + n`，前 `m` 个是有效元素，后 `n` 个为 `0`（占位）
- 要求**原地修改** `nums1`，不能开新数组返回

**示例**：`nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3` → `[1,2,2,3,5,6]`

---

## 思路

**核心 insight：从后往前填**。

- `nums1` 后半部分是空位，**从尾部往前写永远不会覆盖还没读到的数据**
- 维护三个指针：
  - `p1` 指向 `nums1` 有效部分的尾（`m-1`）
  - `p2` 指向 `nums2` 的尾（`n-1`）
  - `p` 指向 `nums1` 真实的尾（`m+n-1`，即要填入的位置）
- 每次比较 `nums1[p1]` 和 `nums2[p2]`，把**大的**放到 `p` 位置
- `nums2` 若有剩 → `arraycopy` 倒进去；`nums1` 若有剩 → 本来就在原位，不用动

**为什么不能从前往后？** 会覆盖 `nums1` 还没读的元素，需要额外 O(m+n) 空间。

---

## 解法

```java
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        int p1 = m - 1;
        int p2 = n - 1;
        int p = m + n - 1;
        while (p1 >= 0 && p2 >= 0) {
            if (nums1[p1] > nums2[p2]) {
                nums1[p--] = nums1[p1--];
            } else {
                nums1[p--] = nums2[p2--];
            }
        }
        // nums2 剩余的倒进 nums1 头部；若 p2 = -1 则拷贝 0 个，安全
        System.arraycopy(nums2, 0, nums1, 0, p2 + 1);
    }
}
```

**复杂度**：时间 O(m + n) · 空间 O(1)

---

## 复盘

- ✅ 一次过，反向双指针的思路自然就想到了
- ✅ 收尾用 `arraycopy(nums2, 0, nums1, 0, p2 + 1)` 一行替代第二个 while，干净
- 💡 套路记忆：**有序数组原地合并 → 从后往前双指针**（避免覆盖 = 空间 O(1)）
- ⚠️ 易错点：
  - 不是 `arraycopy(..., p2)`，是 `p2 + 1`（剩余元素个数 = 下标 + 1）
  - `p2 = -1` 时 `p2 + 1 = 0`，arraycopy 拷贝 0 个，**不会越界，是天然合法的 no-op**
  - 不需要处理 `nums1` 剩余：本来就在它该在的位置

## 面试加分点

被问到这题如果回答**反向双指针**，面试官多半会追问：

> "如果题目改成 nums1 没有预留空位，要返回一个新数组呢？"

→ 那就退化为**从前往后双指针 + 新数组**，时间还是 O(m+n)，但空间变 O(m+n)。**这道题的所有'技巧'都建立在'nums1 后段有空位'这个前提上**——把这个前提说出来，就显得思考很完整。
